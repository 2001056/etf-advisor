## 부록 B. 이 문서가 스스로 정정한 사실

검토 과정에서 초안의 오류 몇 가지가 드러났다. 같은 실수를 피하기 위해 남긴다.

1. **④ 보유 점검의 관측치가 이미 있었다.** 초안은 `data/logs/run-1.log`를 "DB 리셋 후 남은 고아 로그"로 두 번 언급하고 열지 않았다. 열어보니 ④의 첫 실행 기록(2026-08-31 12:58 KST, 보유 2종목, code=0)이었다.
2. **토큰 배율이 두 척도를 섞어 7.7배 틀렸다.** ④만 로그척도(149,838), 나머지는 DB척도로 나눠 54×/26×/60×라는 값을 냈다. 정정하면 7.05×/3.35×/7.82×다. 이 오류는 "④가 매일 켜져도 부담이 작다"는 결론과, 검증 절차에 박힌 비교 기준까지 오염시킬 뻔했다.
   → **교훈: `[확인됨]` 표기는 그 숫자의 출처를 보증할 뿐, 서로 다른 숫자 사이의 비교 가능성을 보증하지 않는다.**
3. **주간 한도 `%p`는 측정 도구로 쓸 수 없다.** 정수 반올림 때문에 ④ 1회(≈0.14%p)는 항상 0으로 기록된다. 재검토 트리거를 토큰 기준으로 바꾼 이유다(§8).
4. **"9월 배정액 140만원" 우려는 해소됐다.** 관측 시점(09-02 11:45~11:48)에는 온보딩 시딩 70만 + 9월 충전 70만으로 140만원이었으나, 이후 사용자가 온보딩 시딩을 정리해 현재는 **70만원**이며 매입 규칙과 일치한다.
